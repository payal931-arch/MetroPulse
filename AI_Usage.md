# AI Usage

## Overview

AI assistance was used during the development of the MetroPulse project as a learning and development tool.

The project was still developed, tested, checked, and reviewed as part of the normal development process.

## Where AI Assistance Was Used

AI was used for some parts of the project, including:

* Understanding the project requirements and breaking them into smaller steps.
* Explaining Python, SQL, DuckDB, Git, and Streamlit concepts.
* Helping troubleshoot development and execution issues.
* Reviewing SQL transformations and data-quality checks.
* Suggesting improvements for data ingestion, retry handling, and repeated runs.
* Helping organize the README and other project documentation.
* Reviewing the dashboard structure and usability.
* Helping understand analytical results and identify areas that needed checking.

## Human Validation

AI suggestions were reviewed and tested during development.

The following parts were run and checked locally:

* Data ingestion scripts
* DuckDB database rebuild
* SQL transformations
* Data-quality tests
* Dashboard data export
* Streamlit dashboard
* Git repository workflow

The results shown in the project come from the processed datasets and the project pipeline. They were not manually created or entered just to produce the results.

## Transparency

AI was used as a supporting development tool. It was not used to present unverified results as actual project findings.

Any AI-generated suggestions used in the project were reviewed and adjusted to match the actual data, implementation, and project requirements.
